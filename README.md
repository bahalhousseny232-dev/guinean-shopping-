# Guinean Shopping

Application mobile de boutique en ligne développée avec Expo et React Native.

## Démarrage
1. Installer Node.js.
2. Dans ce dossier, exécuter `npm install`.
3. Exécuter `npx expo start`.

## Fichiers
- `App.js` : interface et logique de la boutique.
- `package.json` : dépendances du projet.
- `app.json` : configuration Expo.

Note : le paiement en ligne, les comptes clients, le stock réel et la gestion des commandes nécessitent encore un backend et une intégration de paiement.
